## About

Hi, I'm AcmeX, a robot vision algorithm engineer focusing on:

- **Vision-Language-Action (VLA)** models and multimodal learning
- **World models** for autonomous decision-making
- **Embodied intelligence** in robotic systems

This blog documents technical insights, research explorations, and engineering practices in computer vision and robotics. Built with Astro 5 + Tailwind CSS 4, featuring a minimalist black-and-white design.

## Features

| Category | Description |
|----------|-------------|
| Content Management | Type-safe content system powered by Astro Content Collections |
| Minimalist Design | Black-and-white theme optimized for reading experience |
| Performance First | Static generation with zero JavaScript runtime |
| Smart Categories | Multi-dimensional organization: Paper Research, Algorithm Implementation, Project Practice |
| RSS Feed | Auto-generated RSS feed for subscription |
| SEO Optimized | Automatic sitemap generation for search engines |

## Quick Start

```bash
git clone https://github.com/AcmeX/blog.git
cd blog
npm install
npm run dev          # Start development server
npm run build        # Build for production
npm run preview      # Preview production build
```
