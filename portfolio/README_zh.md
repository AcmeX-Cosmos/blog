## 项目简介

个人作品集网站，展示**机器人视觉感知**与 **ROS2 系统架构**领域的项目成果、技术能力与职业经历。采用 Vue 3 + Vite 构建，响应式暗色主题设计。

## 功能特色

| 分类 | 说明 |
|------|------|
| 项目展示 | 分类展示机器人视觉、ROS2 系统、仿真等方向的项目作品 |
| 个人经历 | 时间线形式呈现教育背景与职业发展轨迹 |
| 技能雷达 | 可视化展示技术栈与能力维度 |
| 响应式设计 | 适配桌面端与移动端浏览 |
| 暗色主题 | 深色科技风格，突出视觉冲击力 |

## 快速开始

```bash
git clone https://github.com/AcmeX/portfolio.git
cd portfolio
npm install
npm run dev          # 启动开发服务器
npm run build        # 构建生产版本
npm run preview      # 预览生产构建
```
