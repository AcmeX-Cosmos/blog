## 项目简介

你好，我是 AcmeX，机器人视觉算法工程师，研究方向包括：

- **Vision-Language-Action (VLA)** 模型与多模态学习
- **世界模型 (World Models)** 在自主决策中的应用
- **具身智能 (Embodied Intelligence)** 系统设计

本博客记录计算机视觉与机器人领域的技术洞察、研究探索与工程实践。采用 Astro 5 + Tailwind CSS 4 构建，极简黑白主题设计。

## 功能特色

| 分类 | 说明 |
|------|------|
| 内容管理 | 基于 Astro Content Collections 的类型安全内容系统 |
| 极简设计 | 黑白配色，优化阅读体验 |
| 性能优先 | 静态生成，零 JavaScript 运行时 |
| 智能分类 | 多维度内容组织：论文研究、算法实现、项目实践 |
| RSS 订阅 | 自动生成 RSS Feed 支持订阅 |
| SEO 优化 | 自动生成 Sitemap 优化搜索引擎收录 |

## 快速开始

```bash
git clone https://github.com/AcmeX/blog.git
cd blog
npm install
npm run dev          # 启动开发服务器
npm run build        # 构建生产版本
npm run preview      # 预览生产构建
```
